# 프로필 관리 웹 앱

이름, 소개, 이미지 URL, 프로필 링크를 카드 형태로 관리하는 HTML·JavaScript 앱입니다. 프로필 목록은 현재 브라우저의 `localStorage`에 저장합니다.

## 기능

- 이름·소개·링크를 입력해 프로필 추가
- 이미지 URL 미리보기와 프로필 카드 표시
- 프로필 삭제 및 브라우저 재방문 시 목록 복원
- 설치 안내를 위한 동적 Web App Manifest

## 실행

Python 3가 설치되어 있다면 저장소 루트에서 실행하세요.

```bash
python3 -m http.server 8000
```

`http://localhost:8000`을 엽니다. 별도의 패키지 설치나 빌드 과정은 없습니다.

## 구조

| 파일 | 역할 |
|---|---|
| [index.html](index.html) | 입력 폼, 카드, 저장 로직, 설치 관련 코드 |
| [style.css](style.css) | 반응형 레이아웃과 스타일 |

## 저장 및 설치 범위

프로필은 브라우저·기기별로 보관되며 계정 동기화 기능은 없습니다. 사이트 데이터를 지우면 프로필도 삭제됩니다. 이미지와 아이콘 CDN을 불러올 때는 인터넷 연결이 필요합니다.

현재 Service Worker는 Blob URL로 생성해 등록하는 구현이며, 브라우저에서 등록이 거부될 수 있습니다. 기본 프로필 관리 기능과 PWA 설치·오프라인 동작을 구분해서 확인하세요. 완전한 오프라인 앱으로 검증된 상태는 아닙니다.
